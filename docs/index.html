Kom i gang på 2 minutter

To måter å koble til på, avhengig av hvilken agent du bruker.

🚀 OAuth (anbefalt)

For Claude Web, Claude Mobile, Claude Desktop og ChatGPT med MCP-støtte.

Lim inn denne adressen som tilkobling i klienten din:

https://mcp.firmaradar.no/mcp

Du logger inn via firmaradar.no-konto og velger hvilken API-nøkkel agenten skal bruke. Ingen legitimasjon trengs på klient-siden.

Detaljert veiledning per klient: firmaradar.no/koble-til-agent

📦 API-nøkkel via stdio

For Cursor, Codex eller andre klienter uten støtte for ekstern MCP.

Installer pakken og legg til i klientens konfigurasjonsfil:

pip install firmaradar-mcp
{
  "mcpServers": {
    "firmaradar": {
      "command": "firmaradar-mcp",
      "env": {
        "FIRMARADAR_API_KEY": "din-nøkkel",
        "FIRMARADAR_API_BASE": "https://firmaradar.no"
      }
    }
  }
}

Hent API-nøkkel: firmaradar.no/min-side/api-keys

Hvorfor åpen kildekode?

Server-pakken (denne) er Apache 2.0. Du kan lese, gå gjennom og forke den fritt. Selve datakilden (firmaradar.no) er proprietær fordi den eier dataflyten og lisensieringen mot Skatteetaten og Brønnøysund.

🔍 Transparens

Hver verktøy-modul ligger åpent. Du kan se nøyaktig hva agenten sender til Firmaradar — ingen skjulte felter.

🔒 Tillit gjennom gjennomgang

Lås til en spesifikk versjon, kjør din egen SBOM-skanning, eller fork-en og kjør på din egen infrastruktur.

🤝 Bidrag velkommen

Forbedringer i skjemaer eller kompatibilitets-lag for nye agent-klienter tar vi gladelig imot.

Sikkerhet og GDPR

Bygget for produksjons-bruk i regulerte bransjer (advokat, KYC, revisjon, finans).

  • OAuth 2.0 og PKCE (RFC 7636), Dynamic Client Registration (RFC 7591), Protected Resource Metadata (RFC 9728)
  • Delegerte tokens i PostgreSQL, knyttet til kundens valgte API-nøkkel — kan tilbakekalles uavhengig
  • Loggføring per kall (kunde, nøkkel, endepunkt og status) — eksporteres via DSAR-rapport
  • Person-data pseudonymisert på serversiden; sikkerhetskopier kryptert og lagret eksternt
  • Norsk lov og GDPR-tilpasset: behandlingsgrunnlag, samtykke, oppbevaringstid

Full sikkerhets-policy: firmaradar.no/personvern
